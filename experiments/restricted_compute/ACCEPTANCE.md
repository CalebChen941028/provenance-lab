# 受限计算原型验收标准 v1（2026-11-02）

用途：验收独立本地原型，不接入正式工作流，不启动模型或改变用户配置。下列门槛冻结后逐项执行，失败修实现，不删用例或放宽断言。本轮原始科研产物及D52-1历史裁决保留。

| 编号 | 门槛 | 通过证据 |
|---|---|---|
| A1 环境 | 使用本机已有macOS进程沙箱；无可用后端即失败，不回落为裸执行 | 普通进程能读合成原数据；同UID受限进程被内核拒绝；无安装或模型调用 |
| A2 访问边界 | 受限reader不能读取private及登记的源数据域，不能向外复制，不能改程序/注册表 | cat/head、Python子集/单元格、编码、stderr/异常、复制/遍历路径、符号/硬链接、子进程及嵌套宽松沙箱均实际执行并拒绝；私有记录不可读；网络连接拒绝 |
| A3 任务入口 | 只允许固定审核程序和两个已注册任务，参数不能含任意代码、命令或路径 | 非法/额外字段、错任务/数据集、程序及输入指纹变化在计算前拒绝；没有任意执行回落 |
| A4 输出发布 | 不把worker stdout/stderr或异常直接发布；只发布固定结构汇总及由宿主生成的图件 | worker实际打印原始/编码内容时，仅私有日志留证；reader不能读日志；无效/缺失/超限/重复键/非有限数/额外字段均拒绝，不泄露原始结果 |
| A5 正常功能 | 正常汇总、源行键核对及图件可交付 | 合成数据的样本量、均值、斜率与独立有理数参考一致，分箱计数正确；SVG可解析、计数比例和哈希正确；允许文件可读 |
| A6 行键 | 源行键在缺失筛选、排序后仍能定位原记录 | 合成定位对照通过；D52已确认的15项用独立重跑数据副本核对15/15；原错误子集位置被拒绝；不把计数或系数一致代替定位验证 |
| A7 有限资源 | 读取返回及计算输出有字节、时间限制；错误失败关闭 | reader超量及超时（含关闭输出管道后仍运行）被终止；worker输出超量、超时不产生成功返回；错误仅含通用码及不透明记录ID |
| A8 可复现与保留 | 两种本机Python执行同一组测试，无跳过/失败/异常；原数据、正式代码和安装配置不变 | Python3.13与系统3.9结果、最终代码指纹、208原文件及正式执行文件/六安装文件/配置指纹核对、git diff检查和文案lint |

上述各项均满足，才判“本地原型在指定测试边界通过”。已审核固定程序和配置由可信宿主持有；原始数据不得预先放入public，未登记的外部副本也不在本轮保护域中。允许的汇总是明确的信息发布，不宣称差分隐私，不对恶意宿主或误批准的程序作保密保证。

ZCode接入单独列为“待验证”：现有ZCode进程尚未由本原型启动，普通同UID非受限进程仍能读文件。该负对照必须保留；它不使受限reader的实际拒绝失效，也不能被隐去而声称当前ZCode已隔离。ZCode实接入须证明所有相关读取/执行入口经过边界、受信任宿主与reader隔离、既有检索和图表任务可用；本轮不安装配置或用付费模型补证。
