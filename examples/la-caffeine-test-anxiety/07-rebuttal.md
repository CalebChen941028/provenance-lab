### Comment 1.3 目标值 0.20 比唯一同构念估计（ρ=0.31）与自引荟萃（SMD=0.94）都小，这个选取自由度为什么不算有利选择，扣掉几分预注册光环？

**Response 1.3** 分三层回答。

第一层，口径匹配。0.31 是频次量杯口径的 Spearman ρ[15]，SMD=0.94 是剂量分组的标准化均数差[4]，两者与连续 mg/d × 连续得分的 Pearson r 不同量纲，均不可直接锚定。同口径（连续 mg/d × 连续得分）的实测正向估计是 r = 0.137[2] 与 0.258[5]，0.20 取在该区间内。SAP §1.1（03-sap.md:19）记录了这一锚定逻辑。

第二层，"有利选择"的方向恰好相反。有利选择是选容易检出的参数；0.20 是区间内更难检出的保守端——80% 与 90% 效能的最小可检 r 分别为 0.162 与 0.186（SAP §1.4，03-sap.md:41），0.20 紧贴 90% 档。锚 0.31 会让效能、CI 宽度、"小到中等"定性全部变得更好看，我们没有这么做。

第三层，光环扣分。同意：目标值选取是设计自由度，预注册冻结的价值不能覆盖它——冻结保证的是"结果知晓后不换参数、不换模型、不选择性报告"（D5 与 table-S2 可核验），不保证参数本身无偏。稿件 §2.2 本轮已补"该选取含设计自由度，其辩护来自口径匹配论证而非预注册本身（§4.3）"，§4.3 说明一并登记。扣几分不由我们自己评，缺口已如实入稿。

**修订落点**：标题页期刊注；§2.2 目标值口径段重写；§4.1、摘要、§5 验收口径升级；§4.3 说明一。

### Comment 2.3 Null-B 实测 0.0565 距上沿仅 0.0031（约 1.3 个 MC-SE），如何排除校准残差抬上去的贴边通过？

**Response 2.3** 用本次会话实际运行的解析估算定量排除（.venv/bin/python，scipy）：

- 校准残差的真实值：run-all-console.log 记录 Null-B 校准 3 次迭代收敛于骨架 0.04418，400 集平均偏相关 = **−0.00014**（不是容差上限 +0.004，且符号为负——方向上压低而非抬升拒绝率）。
- 即使残差顶格取容差 +0.004，对 M1 β₁ 检验水平的抬升上界：λ = atanh(0.004)·√294 = 0.0686，双侧拒绝率 = 0.05053，抬升 **+0.00053**。
- 观测偏离 0.0565 − 0.05 = 0.0065 = **1.33 个 MC-SE**（SE = √(0.05×0.95/2000) = 0.00487）。

校准残差的最大贡献（0.00053）比观测偏离（0.0065）小一个数量级，且实际残差方向相反。"贴边 = 残差抬高"在数值上不成立；0.0065 的偏离就是 2,000 次重抽的随机波动。同时如实承认两点：真校准完美时单带外概率 5%（两带均落入约 0.90），本次落入带内不构成对水平正确的强证据，只是未拒绝；0.0545 与 0.0565 同落上半区在 2,000 次口径下无异常（分别 0.92 与 1.33 个 SE），但若要压缩这份解释的不确定性，正式版的合格判定应提高重抽次数（如 10,000 次，SE 降至 0.0022）——已写入 §4.4 预注册改进方向。

**修订落点**：§4.3 说明三；§4.4 预注册清单（中止条款；重抽次数提升为预注册版考虑项）。

## Reviewer 3（模型复杂度与共线性）

### Comment 3.1 条件数超阈后当场换列标准化口径放行，与"未发生结果知晓后的模型选择"（D5）如何区分？若按原始口径触发，预注册的后续处理是什么？

与 D5"无结果知晓后的模型选择"的区分：条件数口径选择没有改变任何模型设定、任何推断、任何结果数字，它改变的是一段诊断讨论文字的写法；D5 针对的是模型与检验的选择。且口径选择有独立的文献依据而非事后挑选——Belsley 教科书（SAP 方法文献 #20）明确原始尺度条件数对列量纲敏感、判定应基于列标准化口径，这正是 κ=32.02 被判为"截距常数 + 未缩放协变量的量纲性假信号"的出处。

## Reviewer 4（测量效度）

### Comment 4.1 引言说女性考试焦虑更高（[17][18][19]），生成机制却锚全女性样本边际、性别零相关——两处哪一处代表建模判断？全女性锚对混合总体边际是否偏高？

### Comment 4.2 暴露以 FFQ 命名却按零测量误差真值注入，真实 FFQ 的衰减会让效能与效应量预期整体失效；"换数据源即用"包不包括测量误差层？

**Response 4.2** 不包括，且失效判断正确。SAP 的生成结构里没有测量误差模型：暴露列是对数正态真值 mg/d，"FFQ 式口径"只定义了口径含义（咖啡+茶+能量饮料+可乐的总量估算），没有模拟回忆偏倚与效度衰减。经典测量误差对相关结构的效应是衰减（观测 r ≈ 真值 r × 信度因子），这意味着：0.937 的效能与 1.25 的斜率预期都是真值口径数字，搬到真实 FFQ 数据时观测相关会缩水、效能随之下降，样本量须按预期效度重估。"沿用同一 SAP 更换数据源"的承诺范围是分析层（模型、检验、校正、判定规则），不含测量层——这句话原稿没写，是真实缺口。已修订：§4.3 其三整段补写测量误差层未建模与样本量重估要求；衰减系数的具体数值无法从工作区材料给出（白名单内无咖啡因 FFQ 效度研究），列入 unanswered。

**修订落点**：§4.3 其三、说明二；§4.4 清单（重锚边际、按效度重估样本量）。

**Response 6.1** 实际验证的是主干路径：生成-校准-冻结-完整性门-H1a/H1b-诊断读数-多重校正-MC 校准-CV。未验证的是三块：多重插补（零缺失未触发）、HC3 重报（BP p=.970 未触发）、RESET 触发后的 M2 升级注记（p=.845 未触发）——这些分支代码在本次演示中一次都没执行过，正确性未经运行验证；真实数据首次触发即为生产首跑。原稿"直接工作模板"（§5）的说法把主干验证扩大成了全模板验证，是过头外推。已修订：§4.3 新增边界其五（分支零执行与压测要求），§5 结论改为"模板的条件分支与竞争生成场景尚未压测（§4.3 其五），真实数据版据此补验后启用"，§4.4 清单加入"为条件分支补构造触发场景的压测记录"（注入缺失与异方差的冒烟数据集）。

### Comment 6.2 反向[13]、非线性[14]、性别特异[9][10]三种竞争结构一个都没压测，等于把确认偏倚内建进"流程验证"；这个风险为什么不在边界清单里——边界是不是挑着写？

**Response 6.2** 边界确实挑着写了：原四条覆盖了模拟总体、横断方向、暴露口径、单层结构，没有覆盖"演示只选了预期成立的正向线性场景"这一确认偏倚——而竞争结构的文献就在同一份稿件的引言里，这个遗漏没有借口。已修订：§4.3 其五补"反向路径[13]、非线性[14]与性别特异[9][10]三种竞争生成结构未压测，演示只覆盖预期成立的正向线性场景"；§4.4 对应补压测承诺。要说明的是压测的定位：对演示结论（参数回显）无影响——回显不依赖场景；受影响的是"模板已验证"主张的适用面，修订后的表述（主干已验证、分支与竞争场景待压测）与实际验证内容对齐。

**修订落点**：§4.3 其五；§5；§4.4。
