运行口径：provenance-lab pipeline · development 严格度 · 无真实数据，分析阶段以固定种子模拟横断数据演示（n=300，相关与回归）。本文档为 S1 立题产物，供 S2 文献检索、S4 统计分析计划（SAP）与后续分析角色继承。学科领域判定：心理学（psychology），最邻近主域为心理学，检索路由按 psychology 加挂 arXiv（定量方法）。本版为 R1 修订版：吸收方法学评审 5 条意见（目标相关层级校准、H1b 斜率口径、假设方向与检验口径统一、二分敏感性解读规则、TAS 量表值域），逐条修订记录见文末。

## 1 研究背景与立题依据

### 1.1 结局：考试焦虑在大学生群体中高发且测量工具成熟

考试焦虑是评价情境下情绪紧张、担忧认知与生理唤醒交织的心理构念，影响学业表现与心理健康。Sarason 考试焦虑量表（Test Anxiety Scale, TAS）为 37 项真假判断条目 0/1 计分的自陈工具，总分理论值域 0–37（量表结构见 Table 4 脚注 a）；中国护理专业大学生的横断调查（n=791）显示 TAS 均分为 18.42（*SD* 7.96），且与睡眠拖延、注意问题构成可检验的关联网络[1]。测量层面，自陈量表之外的客观化工具也在发展：计算机化绩效评价焦虑任务（PEAT）在高考试焦虑者中检出更显著的唾液皮质醇升高，为该构念提供了生理校验[2]。结局变量具备标准化量表、已发表常模参数与生理效度三重支撑。

### 1.2 暴露：咖啡因是大学生使用最广的精神活性物质，作用通路指向焦虑

美国中西部大学 1125 名本科生的横断调查显示，超过 60% 的学生匹兹堡睡眠质量指数（PSQI）判定为差睡眠者，咖啡因与处方药、非处方药一并列入其精神活性物质使用谱[3]。儿科学会的政策综述进一步把咖啡因摄入列为青少年与年轻成人睡眠不足的可干预成因[4]。咖啡因经腺苷受体拮抗与皮质醇轴激活产生提神效应，同时伴随唤醒水平升高；考试季的大学生恰好把咖啡因用作应对学业压力的工具，暴露与结局在同一人群中高频共存。睡眠是这条通路上的关键节点：摄入影响睡眠，睡眠受损放大焦虑，三者在横断数据中构成典型的混杂结构。

### 1.3 证据空白：焦点暴露与特定结局的直接估计缺位

立题勘察在 EuropePMC 执行检索式 `caffeine AND ("test anxiety" OR "examination anxiety")`（2026-10-23，命中 141 条，读取题录头部 4 条）：命中的考试焦虑研究以经前综合征、职业失衡为暴露变量[1]，头部未见以咖啡因摄入为焦点暴露、考试焦虑为结局的横断关联估计。学业压力相关的学生横断研究普遍把咖啡因摄入放进协变量列表而非研究焦点[5]。同类行为—心理症状关联在大学生横断数据中量级小而稳定：生活方式与膳食习惯研究中 BMI 与经前症状严重度相关 *r* = 0.111（*p* = 0.013，n = 502）[6]。据此判断，咖啡因摄入量与考试焦虑得分的直接关联估计存在空白，该判断待 S2 三库全量检索核实。

### 1.4 立题定位与数据口径

本研究采用两段式定位。演示段：在无真实数据的现实约束下，以固定种子模拟横断数据（n=300）执行相关与回归分析，打通"检索—立题—SAP—分析—报告"全链条并验证可复现性；模拟参数锚定已发表真实量级（Table 3），结论仅描述模拟总体。应用段：真实数据到位后沿用同一 SAP 更换数据源，立题结构、假设与报告规范不变。

## 2 研究问题与假设

### 2.1 研究问题

在（模拟）在校本科生中，日均咖啡因摄入量与考试焦虑得分是否存在正向横断关联？调整性别、年级与睡眠质量后，该关联是否持续存在？

### 2.2 PECO 结构

**Table 2** 研究问题 PECO 结构表

| 要素 | 内容 |
|---|---|
| P（人群） | 在校本科生，模拟口径 18–25 岁，n = 300（真实数据版为考试季在校本科生） |
| E（暴露） | 日均咖啡因摄入量（mg/d），食物频率问卷口径估算咖啡、茶、能量饮料与可乐贡献，连续变量；辅助二分 < 100 vs ≥ 100 mg/d |
| C（对照） | 连续变量内的低摄入水平（每增加 100 mg/d 的对比；二分口径以 < 100 mg/d 组为参照） |
| O（结局） | 考试焦虑得分，TAS 总分（连续） |
| S（研究设计） | 横断面观察性设计，固定种子模拟数据演示 |

### 2.3 可检验假设

**Table 3** 假设与检验框架

| 编号 | 假设（H0 / H1） | 主对应分析 |
|---|---|---|
| H1a | H0：*r* = 0；H1：*r* ≠ 0（双侧）——咖啡因摄入量与 TAS 得分存在线性相关，预期方向为正；模拟目标边际真值 *r* = 0.20（定义在变换后边际，校准见 3.2） | Pearson 相关（双侧 α = 0.05） |
| H1b | H0：*β*₁ = 0；H1：*β*₁ ≠ 0（双侧）——调整性别、年级、睡眠质量后，摄入量每增加 100 mg/d 与 TAS 得分变化非零，预期方向为正；调整后真值斜率 ≈ 1.25 分/100 mg·d⁻¹（未调整边际 ≈ 1.47，见 3.2） | 多重线性回归（双侧 α = 0.05） |
| H2（探索性） | H0：*β*₂ = 0——关联呈线性，剂量-反应曲线无二次项成分 | 回归中加入摄入量二次项 |

### 2.4 样本量与检验效能

样本量 n = 300 为用户指定的演示口径。Fisher-z 法核算（α = 0.05 双侧，本会话 python3 实算）：真值 *r* = 0.20 时效能 0.937，*r* = 0.17 时效能 0.841；80% 效能的最小可检相关为 *r* = 0.161，90% 效能为 *r* = 0.186。两个假设分别按各自量级核对效能：H1a 的目标边际 *r* = 0.20 对应效能 0.937；H1b 按 Table 4 相关结构（PSQI-摄入 0.15、PSQI-TAS 0.25）扣除睡眠混杂后，解析偏相关为 0.170（模拟实测 0.176），恰对应 *r* = 0.17 档的效能 0.841，调整模型的设计效能按 0.84 口径报告。目标真值位于同类行为—心理关联量级区间（*r* ≈ 0.11–0.20）[6]上沿，两口径效能均不低于 0.80；n = 300 下 *r* = 0.20 的期望 95%CI 约为 [0.09, 0.31]，区间不含 0，演示精度满足回归示范需求。

## 3 设计与报告规范

### 3.1 总体设计

横断面观察性设计，模拟数据演示口径。暴露与结局在同一（模拟）时点测量，因果定位为关联估计，不做因果推断陈述。

### 3.2 模拟数据生成方案（SAP 定稿，本表为锚定方案）

**Table 4** 模拟数据生成参数与真实锚定

| 变量 | 生成分布与参数 | 真实锚定来源 |
|---|---|---|
| n | 300 | 用户指定 |
| 随机种子 | 固定（示例 20261023，SAP 锁定） | 复现性要求 |
| 咖啡因摄入量（mg/d） | 对数正态，中位数 ≈ 130，截断 [0, 800] | 大学生膳食调查常见量级[3][4] |
| TAS 总分 | 正态 N(18.4, 8.0)，截断 [0, 37]（量表值域 0–37，脚注 a） | 中国护理本科生实测均分 18.42（7.96）[1] |
| 目标真值关联 | 咖啡因×TAS 目标边际 *r* = 0.20，定义在变换后边际（脚注 b） | 同类行为—心理关联 *r* = 0.111–0.20[6] |
| 睡眠质量（PSQI 总分） | 与摄入量边际 *r* ≈ 0.15（高摄入→睡眠差），与 TAS 边际 *r* ≈ 0.25 | 通路证据[3][4] |
| 性别 | Bernoulli(0.55)（SAP 可调） | 演示设定 |
| 年级 | 均匀分布 1–4 | 演示设定 |

脚注 a：TAS 为 Sarason 37 项真假判断（0/1）计分量表，总分理论值域 0–37（Encyclopedia of Psychological Assessment「Test Anxiety」词条；APA PsycTests 记录 doi:10.1037/t01390-000）。N(18.4, 8.0) 下 P(X > 37) = 0.010，截断上限取 40 会生成约 1% 量表理论上限之外的分数，故值域取 [0, 37]。
脚注 b：目标相关定义在变换后（对数正态/截断正态）边际，而非高斯骨架相关。骨架到边际存在收缩（40 万次蒙特卡洛实测收缩因子 0.924），骨架相关须反解至 ρ* ≈ 0.216 或生成后迭代校准；复现性检查要求实测边际 *r* 与目标 0.20 的偏差 ≤ 0.01。

生成方式：按相关阵构建高斯骨架，再依 Table 4 边际分布单调变换，目标相关定义在变换后边际。骨架到边际的收缩经 40 万次蒙特卡洛实测（seed 20261023，含 [0, 800]/[0, 37] 截断）：未校准骨架 ρ = 0.20 时实测边际 *r* = 0.185、摄入量 *SD* = 108.2 mg/d、TAS *SD* = 7.73，效能跌至 0.896；骨架相关反解至 ρ* ≈ 0.216 后实测边际 *r* = 0.203、效能 0.944，满足目标。生成后以实测 *r* 与目标 0.20 的偏差（容差 ±0.01）作为复现性检查项写入 SAP。真值斜率分两个口径（校准方案模拟实测）：未调整边际斜率 ≈ 1.47 分/100 mg·d⁻¹（解析近似 0.20×8.0/110×100 = 1.45）；调整性别、年级、PSQI 后 ≈ 1.25 分/100 mg·d⁻¹，对应解析偏相关 0.170、模拟偏相关 0.176。调整前后的斜率差即睡眠混杂的效应演示。具体协方差结构与校准程序在 SAP 定稿并预注册。

### 3.3 统计分析框架

主分析为 Pearson 相关（报告 *r*、95%CI、*p*）；调整模型为多重线性回归（TAS ~ 摄入量 + 性别 + 年级 + PSQI，报告非标准化 *β*、95%CI、*p*、*R*² 与标准化 *β*）；敏感性分析含 Spearman ρ（应对摄入量右偏）与暴露二分口径（独立样本 *t* 检验加调整模型）。二分口径的解读规则于 SAP 预注册：< 100 mg/d 组占比约 34%（对数正态边际实测），二分衰减后点二列 *r* ≈ 0.17、对应效能约 0.85，低于连续口径的 0.94；若结果出现"连续口径显著而二分口径不显著"，判定为二分信息损失的设计属性而非结论不稳，主结论以连续口径为准。H2 以二次项检验线性充分性。统计量按 APA/JARS 报告：*p* < .001（不写 *p* = 0.000），95%CI [LL, UL]，M (*SD*)。调整前后 *β* 变化幅度作为睡眠混杂的演示指标。全部随机过程由固定种子控制，脚本与种子入审计包。

### 3.4 报告规范

采用 STROBE 横断面条目。模拟口径逐条目显式标注：条目 6"参与者"替换为"模拟样本生成"，条目 12"统计方法"注明数据来源为固定种子模拟；标题、摘要与结论均标明演示性质。模拟结果不外推真实人群，不用于发表或决策。

### 3.5 混杂与偏倚结构（模拟据此注入，真实版据此收集协变量）

睡眠质量为关键混杂变量（与暴露、结局均相关）；性别、年级为人口学调整变量。横断设计的核心局限是暴露与结局同点测量带来的时序不明，以及自陈摄入量的回忆偏倚，两者作为适用边界写入报告讨论章节。
