## 1 目的与设计

### 1.1 研究目的

本研究回答两个确证问题和一个探索问题。第一，估计大学生日均咖啡因摄入量（mg/d）与考试焦虑得分（TAS 总分）之间的横断线性关联强度。第二，检验该关联在调整性别、年级与睡眠质量（PSQI 总分）后是否持续存在。第三（探索），检验剂量-反应关系对线性模型的偏离是否需要二次项。证据表内同类关联的实测量级为 *r* = 0.137–0.31（考试焦虑口径 Spearman ρ = 0.31[1]；一般焦虑口径 *r* = 0.137、0.258[2][3]），目标真值 *r* = 0.20 落在该区间内。

### 1.2 设计与推断口径

横断面观察性设计，固定种子模拟数据演示，n = 300。暴露与结局在同一（模拟）时点测量，统计推断定位为关联估计，不做因果方向陈述。推断对象是生成机制设定的真值：目标边际相关 *r* = 0.20（定义在变换后边际），未调整边际斜率 ≈ 1.47、调整后斜率 ≈ 1.25 分/100 mg·d⁻¹。结论的解释范围限于模拟总体，不外推真实人群，不用于发表或决策（STROBE 模拟口径逐条目标注，承 01 §3.4）。

暴露以 mg/d 总量为主口径：咖啡因问卷 mg/d 估算[2]与 USDA 数据库 mg/d 口径[4]是证据表中与本设计直接对应的测量方式。睡眠质量进入调整集的依据是咖啡因×睡眠×焦虑三联的横断证据[5][6][7]。品类与总量口径影响检出的教训（巴西：日常黑咖啡显著而总量不显著）[8]由暴露二分与 Spearman 敏感性承担（§4.1、§4.2）。

### 1.4 样本量与检验效能

n = 300 为演示口径（01 定）。Fisher-z 法效能核算（α = 0.05 双侧）：真值 *r* = 0.20 时效能 0.937；80% 与 90% 效能的最小可检相关分别为 *r* ≈ 0.162 与 0.186；*r* = 0.20 的期望 95%CI 为 [0.09, 0.31]，区间不含 0。H1b 按 PSQI 相关结构（摄入×PSQI 0.15、TAS×PSQI 0.25）扣除睡眠混杂后的解析偏相关为 0.170，对应效能 0.8385（本 SAP 按主模型 df = 293 复核；01 报 0.841，按 n − 3 口径，两者一致至小数两位）。两个确证假设的设计效能均不低于 0.80。Holm 校正口径下的效能见 §4.7。

### 2.3 考虑过但排除的候选变量

- 咖啡因品类分项（咖啡、茶、能量饮料单独计量）：模拟框架按总量 mg/d 生成；品类口径对检出的影响[8]在真实数据版按品类再评估。
- 抑郁与问题饮酒：与考试焦虑不同构的结局域，模拟未生成，纳入将引入多结局域膨胀。
- 年龄：与年级高度共线，模拟以年级承载年级效应；18–25 岁窄幅内变异有限。
- 一般焦虑量表（GAD-7、STAI）：结局换用一般焦虑将偏离考试焦虑这一情境性构念（对照证据表条目 1 与 3 的口径分野）。
- BMI 与体力活动：证据表核心条目未将其列为本问题的必要调整变量，模拟未生成；真实数据版按 DAG 再评估。
- 睡眠时长单独条目：PSQI 总分已承载睡眠质量结构[6][7]。

### 2.4 缺失数据处理

模拟按完整数据生成，零缺失为设计要求。实现层若意外出现缺失：缺失记录比例 < 5% 时，主分析为完整个案分析，并以多重插补（m = 20，chained equations，Rubin 规则合并[12]）作敏感性；比例 ≥ 5% 时判生成器缺陷，停止分析，修复并重冻结。单点均值或中位数插补不得进入确证分析。

## 3 主分析

### 3.1 H1a：Pearson 相关

统计量为 caffeine_mg 与 tas_total 的 Pearson *r*（观测尺度）。推断：双侧 *t* 检验（df = 298），α = 0.05；95%CI 用 Fisher z 变换[13]。报告格式：*r*(298) = .xxx，95% CI [.xx, .xx]，*p* = .xxx，并列 *r*²。判定按 Holm 家族规则（§4.7）。

### 3.2 H1b：多重线性回归调整模型

模型 M1：

tas_total = *β*₀ + *β*₁·caffeine_100 + *β*₂·sex_female + *β*₃·grade_y2 + *β*₄·grade_y3 + *β*₅·grade_y4 + *β*₆·psqi_total + ε

检验 H0：*β*₁ = 0（双侧 *t* 检验，df = 293，α = 0.05）。报告：*b*₁（每 100 mg/d 的 TAS 分数变化）及 95%CI、*t*(293)、*p*、标准化 *β*、偏相关 *r*、调整 *R*²，以及相对仅协变量模型的 Δ*R*²。混杂衰减演示指标：（*b*_M0 − *b*_M1) / *b*_M0 × 100%，其中 M0 为仅含 caffeine_100 的未调整模型（表 5）。*β*₁ 为调整 PSQI 后的直接关联口径（Table 3 注），不作总效应解释。

### 3.3 效应量与统计量报告格式

主效应量：*r*（H1a）、偏相关 *r* 与非标准化 *b*₁（H1b）；辅助：标准化 *β*、*R*²、Δ*R*²、Cohen's *d*（仅二分口径，§4.2）。*b*₁ ≈ 1.25 分/100 mg·d⁻¹ 按 TAS 的 *SD* ≈ 7.7 折算约 0.16 个标准差，报告时给出该折算。效应量惯例参照[14]：*r* .10/.30/.50 对应小/中/大；*d* 0.2/0.5/0.8。本结局为连续量表分，不涉及 RR/OR/HR；若真实数据阶段引入二分结局，须另行预注册 logistic 模型并报告 EPV。统计量按 APA/JARS 格式[15]：*p* < .001（不写 *p* = 0.000），95%CI [LL, UL]，M (SD)。

### 3.4 预注册判定与解读规则

1. 确证判定只依据 Holm 校正后的 *p*（F1 家族）、效应方向与 CI 位置；软件原始输出不作二次择优。
2. 实测方向为负时如实报告，标注与预期相反；不改单侧、不取绝对值。
3. H1a 显著而 H1b 不显著时：报告混杂衰减指标与共线性诊断，解释为调整后衰减；不得表述为"调整后无关联"，效应量与 CI 照常报告。
4. 复现性门槛（§1.5 第 4 条）与完整性核查（§6.3）未通过时，不进入下游分析。
5. 全部结论限于模拟总体；横断面证据不做因果陈述。

## 4 次要与敏感性分析

### 4.1 Spearman 秩相关（敏感性）

同一对变量的 Spearman ρ，双侧检验。解读规则：与 Pearson 同向且 FDR *q* < .05，标注"对分布形态稳健"；两口径结论分歧时，主分析以连续口径为准，差异（右偏形态的影响）写入讨论。

### 4.2 暴露二分口径（敏感性）

比较 caff_high 两组（≥ 100 mg/d 组 vs < 100 mg/d 参照组）的 tas_total：独立样本 *t* 检验（df = 298）与调整模型（caff_high 替代 caffeine_100 进入 M1 结构）。效应量：均值差与 Cohen's *d*。预注册解读规则（承 01 §3.3）：设计预期 < 100 mg/d 组占比约 34%，二分后点二列 *r* ≈ 0.17（骨架 0.216 × 衰减因子 0.774 = 0.167），t 检验效能 ≈ 0.83，低于连续口径的 0.94；若出现"连续口径显著而二分口径不显著"，判定为二分信息损失的设计属性而非结论不稳，主结论以连续口径为准[8]。

### 4.3 H2：剂量-反应二次项（探索）

M2 = M1 + caffeine_100_sq。*β*₂ 双侧 *t* 检验（df = 292），BH-FDR 校正（§4.7）。判定规则：*β*₂ 不显著，判线性模型充分，主分析框架不动；显著时报告二次模型、曲率方向与数据范围内的极值点位置，主分析结论框架不变，解释中加入非线性注记。AIC/BIC 仅作辅助描述（Δ ≥ 2 记为值得注意，§5.4）。

### 4.4 年级编码替代口径（敏感性）

grade 以连续 1–4 替代指示变量重拟合（M1ord，df = 296）。判定规则：*b*₁ 相对 M1 的相对变化 < 10% 视为编码不敏感。

| F1 确证 | H1a、H1b | Holm 步降[17]，FWER = 0.05；第一步等价 α′ = 0.025 | H1a 名义 0.937，α′ = 0.025 下 0.895；H1b df = 293 名义 0.8385，若居第一步（α′ = 0.025）为 0.760 | 进入主结论 |

注. Holm 为闭合并有效程序，检验顺序由实测 *p* 决定，规则与 FWER 控制不依赖顺序；两确证假设效能按最不利排序仍不低于 0.76，按预期排序（H1a 居首）为 0.895 与 0.839。

## 5 模型复杂度与过拟合防控

### 5.1 参数量与样本量之比

M1 参数量 k = 7（截距、暴露、性别、年级 3 个指示、PSQI），n/k = 42.9，满足连续结局每参数不少于 10 个观测的保守惯例[19]。M2 与 M3 各 +1 参数，n/k = 37.5。调节项支出只有性别交互 1 df（探索性，§4.6）；确证模型不含任何调节项。EPV ≥ 10 惯例适用于二分结局的事件数口径，本计划确证分析无 logistic 模型，EPV 不适用；若未来引入二分结局的 logistic 敏感性，须另行报告 EPV 并遵循 ≥ 10 惯例。

### 5.2 随机效应结构

数据为单层横断个体记录，无聚类、无重复测量、无分层抽样，确证模型全部为固定效应 OLS，不设随机截距或随机斜率。禁止在结果知晓后引入、简化或复杂化混合效应结构；若后续数据版本引入聚类变量（如班级、宿舍），须回到 §7 变更流程修订 SAP，不得临时改模。

### 5.3 共线性诊断

M1 各预测变量计算 VIF 与模型条件数[20]。阈值：VIF > 5 或条件数 > 30 触发报告与讨论；VIF > 10 时任何合并或重参数化须走变更流程留痕。设计预期：摄入×PSQI 边际相关 0.15，咖啡因对其余预测变量的 *R*² ≈ 0.023，VIF ≈ 1.02，无实质共线；实测超出预期三倍以上时按阈值处置并核对生成器。

### 5.6 零假设蒙特卡洛 type-I 错误率校准

模拟数据口径的必备关卡，先于对演示数据集的任何结果查看：

1. Null-A（H1a 零假设）：保留全部边际与 PSQI 相关结构，迭代校准至 r(摄入, TAS) 边际实测 = 0（|偏差| ≤ 0.005）。
2. Null-B（H1b 零假设）：保留混杂结构，迭代校准至偏相关（控制 PSQI）实测 = 0；此时未调整边际 *r* ≈ 0.04 保留，对应"混杂存在而直接关联为零"的现实零假设（骨架初值 ρ*_ct = 0.1623 × 0.2706 = 0.0439）。
3. 各生成 2,000 个数据集（n = 300，种子见 §6.4），对每个数据集执行 H1a 检验（Null-A 下）与 M1 的 *β*₁ 检验（Null-B 下），名义 α = 0.05 双侧。
4. 合格标准：经验拒绝率落入二项 95% 带 [0.0404, 0.0596]（2,000 次重抽）。不合格时排查检验实现与生成器，修正后重跑校准，不得放宽带。
5. 附带演示输出：Null-B 下 H1a 检验的拒绝率（预期高于 0.05，量化未调整检验的混杂膨胀），仅作教学演示，不设合格带。
